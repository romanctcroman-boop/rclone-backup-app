Privacy policy

Applies to the "rclone" OAuth application of the "rclone personal backup" tool. Last updated: 20 November 2026.

Who uses it

The application is used only by its owner, with the owner's own Google account. It is not offered to anyone else.

What data it accesses

With the owner's permission, the application reads and writes files in the owner's Google Drive. It only copies the owner's own backup files to Drive and reads them back for restore.

Where data goes

  • Files travel only between the owner's computers and the owner's Google Drive.
  • No data is sent to the developer or to any third party. There are no analytics, ads or tracking.
  • The sign-in token is stored only in the local rclone configuration on the owner's computers.

Google API data

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Backup files stay in the owner's Drive until the owner deletes them.
